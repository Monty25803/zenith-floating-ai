# Contributing

1. Open an issue for large changes when possible.
2. Use a feature branch; open a PR against `main`.
3. Keep the main flow: open → paste → **Refactor & Copy**.
4. Never commit API keys or `.env` files.
5. Before PR: `npm run build` and `cargo check` (in `src-tauri`).

Releases are published from `v*` tags or the manual release workflow — not from every commit.
