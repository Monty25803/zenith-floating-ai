# Security Policy

## Reporting a vulnerability

Email or open a private GitHub security advisory for [Monty25803/zenith-floating-ai](https://github.com/Monty25803/zenith-floating-ai).

Do **not** post API keys, credentials, or draft content in public issues.

## Data handling

- Gemini API keys are stored in the OS credential store (Windows Credential Manager).
- Draft text is sent to Google Gemini under your API key when you click Refactor & Copy.
- Refinement history (if used) stays on-device in local storage.
